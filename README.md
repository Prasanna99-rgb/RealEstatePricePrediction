## 📌 Overview

This project is an end-to-end Machine Learning application that predicts California housing prices using the XGBoost Regression algorithm. The model is deployed through a Streamlit web application that allows users to input housing-related features and receive instant price predictions.

The project demonstrates data preprocessing, model training, performance evaluation, model serialization, and deployment in a user-friendly web interface.

## 📊 Dataset Information

The model is trained on the California Housing Dataset containing features such as:

| Feature | Description |
|----------|------------|
| MedInc | Median Income |
| HouseAge | Median House Age |
| AveRooms | Average Number of Rooms |
| AveBedrms | Average Number of Bedrooms |
| Population | Area Population |
| AveOccup | Average Occupancy |
| Latitude | Geographic Latitude |
| Longitude | Geographic Longitude |
